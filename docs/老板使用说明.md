# 视频知识库 · 使用说明

> 把公司的课程视频、PDF、Word、图片变成"能搜、能问"的知识库。
> 不用看完整段 2 小时的视频，也能知道它讲了什么、第几分钟讲了什么。

---

## 一、怎么打开

浏览器输入：`http://<服务器地址>:8010`

- 账号：`boss`
- 密码：管理员提供（登录后 7 天内免登录）

手机浏览器也能打开，界面会自动适应。

---

## 二、三种用法

### 1. 直接问

首页输入框打字，比如：

> 新人培训里报销流程分几步？
> 私域成交的三步法是什么？
> 客户总说考虑考虑怎么办？

答案会先给结论，再给要点。**每条结论后面有时间/页码**，点一下就能跳到原片或原文。

### 2. 找某句话

同样在输入框输入关键词，答案下面会列出最相关的几段，每段都带来源。

### 3. 看内容

左边是内容列表，点开就能看：视频带播放器、PDF 带阅读页、Word 显示原文、图片显示大图。

---

## 三、它能做什么、不能做什么

**擅长**

- 找事实、找原话、找数字
- 跨视频 / 跨资料对比同一件事的不同说法
- 定位到"第几分钟 / 第几页 / 第几段"

**不擅长**

- 画面里的图表细节（只能识别出文字）
- 说得含糊、没有明确写出来的意思
- 资料里根本没有的内容——它会明确说"没有提到"，不会编

---

## 四、内容怎么更新

- 新视频、PDF、Word、图片交给管理员，放进共享目录或网页上传；
- 处理一般需要几分钟到几十分钟（看时长/页数）；
- 处理完在列表里就能看到，标"可用"的才能问答。

---

## 五、用得好不好，看两个地方

1. 答案下面的 **👍 / 👎**——觉得不对就点 👎，管理员会看到并改进；
2. 每周会有一份周报：新增了什么、大家问了什么、哪些问题没答上来。

---

## 六、遇到问题

| 现象 | 怎么办 |
|---|---|
| 打不开页面 | 找管理员确认服务是否启动 |
| 登录不上 | 找管理员重置密码 |
| 某个问题答"没有提到" | 可能资料里确实没有，也可能表述不同；换个说法再问一次 |
| 答案对但引用跳错 | 点 👎 并告诉管理员是哪一条 |

---

## 七、给管理员的一页

| 事项 | 频率 | 命令/位置 |
|---|---|---|
| 检查系统状态 | 每周 | `python healthcheck.py` |
| 看周报 | 每周 | `python weekly_report.py` → `data\reports\` |
| 补内容 | 按需 | 文件丢进 `data\inbox`，或网页「导入文件」 |
| 处理失败 | 按需 | 侧栏回收站旁的失败列表 / `batch.py status` |
| 备份 | 每天自动 | `data\backup\kb-*.zip`，保留 30 份 |
| 改密码 | 按需 | `python set_password.py 新密码` |

**交付清单**

- [ ] 服务地址与账号密码已交给使用者
- [ ] `healthcheck.py` 全部 PASS
- [ ] 最近备份存在且小于 48 小时
- [ ] 开机自启已配置（启动文件夹里的 `KB-Autostart.bat`）
- [ ] 使用者知道"答案可以点引用跳原文"
- [ ] 使用者知道"不知道就问，它会说没有"
