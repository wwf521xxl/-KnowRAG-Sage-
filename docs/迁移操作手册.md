# 迁移到新机器：逐步操作手册

> 适用：把现在这台电脑上的知识库，搬到一台常开的新机器。
> 全程约 1–2 小时，大部分时间在拷贝文件。
> 约定：下文路径都用 `D:\知识库问答系统`，换盘符就整体替换。

---

## 0. 准备清单

| 东西 | 说明 |
|---|---|
| U 盘 / 移动硬盘 | 至少 8 GB（整个目录约 4.3 GB） |
| Python 3.10 安装包 | 官网下载：`python.org/downloads/release/python-31011/`，选 **Windows installer (64-bit)** |
| 新机器 | Win10/11 64 位，插电、接网线 |
| 旧机器 | 能正常打开 `http://127.0.0.1:8010` |

> **先做一件容易被忘的事**：把 F 盘插上，确认 `五天视频课` 那 5 个文件能打开。它们现在显示“源文件缺失”，搬过去也是缺失。

---

## 1. 旧机器：把数据收拢

### 1.1 先确认库是好的

打开 `D:\知识库问答系统`，双击 `start_all.bat`，浏览器打开 `http://127.0.0.1:8010`，随便问一个问题。

### 1.2 停掉服务（避免拷贝时数据库正在写）

在桌面右下角托盘右键 →「退出」；
或者打开任务管理器，结束所有 `python` / `pythonw` 进程。

### 1.3 打包数据（只打数据，不打模型）

PowerShell 里执行：

```powershell
cd D:\知识库问答系统
Compress-Archive -Path data\kb.db, data\library, data\raw, data\courses, data\covers `
                 -DestinationPath "$env:USERPROFILE\Desktop\kb-data.zip" -Force
```

预计大小：**4 GB 左右**（主要是视频原片），耗时 5–15 分钟。

如果只想先搬“文字”（视频以后再说）：

```powershell
Compress-Archive -Path data\kb.db, data\library, data\covers `
                 -DestinationPath "$env:USERPROFILE\Desktop\kb-data-lite.zip" -Force
```

这个只有 **约 100 MB**，问答立刻能用，视频需要另外拷。

## 2. 新机器：装 Python 3.10

1. 双击 `python-3.10.11-amd64.exe`；
2. **勾选最下面的 `Add python.exe to PATH`**（不勾后面全是麻烦）；
3. 点 `Install Now`，等 2 分钟；
4. 验证：按 `Win+R` 输入 `cmd`，执行：

```cmd
python --version
```

应该输出 `Python 3.10.11`。

> 如果提示“不是内部或外部命令”，说明没勾 PATH。重新运行安装包 → `Modify` → 勾选 PATH，或改装到 `D:\python310`。

---

## 3. 拷贝整个目录

把旧机器的 `D:\知识库问答系统` **整个文件夹**拷到新机器同样的位置。

用命令行更快（U 盘盘符假设是 `E:`）：

```cmd
robocopy "E:\知识库问答系统" "D:\知识库问答系统" /E /XD .venv /R:2 /W:2
```

- `/E` 含子目录；
- `/XD .venv` **排除虚拟环境**（它是路径绑定的，拷过去也用不了）；
- 看到 `Ended : ...` 就是完成。

然后把桌面的 `kb-data.zip` 也拷过来。

---

## 4. 新机器：建环境

打开 `D:\知识库问答系统`，**右键 `install_new_pc.ps1` →「使用 PowerShell 运行」**。

如果提示“禁止运行脚本”，打开 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\知识库问答系统\install_new_pc.ps1"
```

如果 Python 没装在默认位置，加参数：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\知识库问答系统\install_new_pc.ps1" -Python "C:\Python310\python.exe"
```

脚本会依次做：建 `.venv` → 离线装依赖（`wheels` 目录）→ 检查模型 → 修数据库路径。

**预期最后几行**：

```
Successfully installed ... (几十个包)
安装完成。
启动：双击 start_all.bat
```

> 失败怎么办：把红字最后 5 行发我。最常见是 Python 版本不是 3.10，或 `wheels` 目录没拷全。

---

## 5. 新机器：把数据放回去

1. 解压 `kb-data.zip`，把里面的 `kb.db`、`library`、`raw`、`courses`、`covers` 覆盖到 `D:\知识库问答系统\data\`；
2. 执行路径修复：

```powershell
cd D:\知识库问答系统
.venv\Scripts\python.exe fix_paths.py
```

**预期输出**：

```
路径修复完成：0 条
```

如果路径一致就是 0 条；如果换了盘符，会逐条打印修复。

3. 启动验证：

```powershell
.venv\Scripts\python.exe kb_server.py 8010
```

浏览器打开 `http://127.0.0.1:8010`，能登录、能问，说明数据没问题。按 `Ctrl+C` 停掉。

## 6. 改密码、换 API Key

### 6.1 改密码

```powershell
cd D:\知识库问答系统
.venv\Scripts\python.exe set_password.py 新密码 boss
```

输出会显示 `username` 和 `password`，**记下来，写进给老板的卡片**。

### 6.2 换 API Key

1. 老板/公司去 `platform.deepseek.com` 注册，充值 100 元，创建 API Key（`sk-` 开头）；
2. 用记事本打开 `D:\知识库问答系统\config.local.json`；
3. 把 `"api_key": "sk-旧..."` 改成新的，保存；
4. 重启服务（托盘退出再双击桌面图标，或面板点「重启」）；
5. 问一个问题验证能答。

> **不要**把 Key 写进任何发给老板的文档，单独发。

## 7. 开机自启（二选一）

### 方式一：登录后启动（要登录）

```powershell
powershell -ExecutionPolicy Bypass -File "D:\知识库问答系统\install_autostart.ps1"
```

它会在启动文件夹放一个快捷方式。重启后**登录桌面**才启动。

### 方式二：开机即启动（不用登录，推荐）

右键 `install_boot_task.ps1` →「使用 PowerShell 运行」，或：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\知识库问答系统\install_boot_task.ps1"
```

它注册两个计划任务 `KB-Server`、`KB-Watch`，开机就跑，与登录无关。

**注意**：
- 两种**只能选一种**，否则开机会起两个服务抢 8010，表现为“时好时坏”；
- 方式二以 SYSTEM 运行，转写可能用不到显卡（会回退 CPU）。如果这台机器要负责转视频，选方式一。

验证：重启电脑 → **不要登录** → 用另一台设备访问 `http://<固定IP>:8010`，能打开就对了。

## 8. 电源设置

### 命令行（管理员 PowerShell）

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /change disk-timeout-ac 0
powercfg /change monitor-timeout-ac 10
```

### 图形界面（笔记本额外设合盖）

控制面板 → 电源选项 → 选择关闭盖子的功能：
- 「合上盖子时」→ **不采取任何操作**（插电那一列）
- 「按电源按钮时」→ 关机（保持默认）

### Windows 更新

设置 → Windows 更新 → 高级选项：
- 打开「活动时间」，设为 8:00–22:00；
- 关闭「尽快获取最新更新」；
- 组策略（专业版）：`计算机配置 → 管理模板 → Windows 组件 → Windows 更新 → 管理最终用户体验 → 配置自动更新 → 2 通知下载并通知安装`。

## 9. 固定 IP

### 首选：路由器绑定 MAC（推荐）

1. 浏览器打开路由器后台（一般是 `192.168.0.1`，账号密码在路由器背面）；
2. 找到「DHCP 服务器 / 地址保留 / 静态分配」；
3. 找到这台机器的 MAC（命令 `ipconfig /all`，看「物理地址」）；
4. 绑定一个固定 IP，例如 `192.168.0.121`；
5. 保存，重启路由器验证。

### 备选：Windows 设静态 IP

设置 → 网络 → 以太网 → IP 分配 → 编辑 → 手动：
- IP：`192.168.0.121`
- 子网掩码：`255.255.255.0`
- 网关：`192.168.0.1`
- DNS：`192.168.0.1`、`223.5.5.5`

> 注意避开路由器 DHCP 池（一般是 `.100–.200`），选池外的地址更稳。

## 10. 防火墙放行

管理员 PowerShell：

```powershell
netsh advfirewall firewall add rule name="KB 8010" dir=in action=allow protocol=TCP localport=8010
```

图形界面：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 8010 → 允许。

## 11. 验收（7 项，缺一不可）

| # | 检查 | 怎么做 | 通过标准 |
|---|---|---|---|
| 1 | 服务自启 | 重启电脑，不登录 | 另一台设备能打开登录页 |
| 2 | 登录 | 输账号密码 | 进入主界面，看到课程卡片 |
| 3 | 问答 | 问 5 个问题（含 1 个没有的） | 4 个有答案且带引用，1 个明确说没有 |
| 4 | 引用跳转 | 点视频/PDF/Word/图片引用 | 分别跳秒、跳页、显示段落、打开图 |
| 5 | 导入 | 丢一个文件进 `data\inbox` | 2 分钟内自动变成“可用” |
| 6 | 自检 | `.venv\Scripts\python.exe healthcheck.py` | 8 项全 PASS |
| 7 | 备份 | 面板点「备份」 | `data\backup` 出现新 zip |

## 12. 收尾

1. 双击桌面「知识库」图标，确认面板正常；
2. 把运维卡打印出来贴机器上：

```
知识库服务机
地址：http://192.168.0.121:8010
账号：boss    密码：见密码条
服务：开机自动启动，不要关机
自检：D:\知识库问答系统\healthcheck.py
故障：先重启机器；不行联系 XXX
```

3. 把旧机器的服务停掉、自启取消（避免两台同时对外）；
4. 把新地址和新密码发给老板。

## 附：常见卡点速查

| 现象 | 原因 | 解决 |
|---|---|---|
| `python` 不是命令 | 没勾 PATH | 重装/修复 Python |
| 脚本被禁止运行 | 执行策略 | 用 `-ExecutionPolicy Bypass` |
| 依赖装不上 | wheels 缺失/版本不对 | 把错误发我，补 wheel |
| 启动报端口占用 | 起了两个服务 | 任务管理器结束多余 python |
| 视频点开 404 | 数据没拷全或路径没修 | 重跑 `fix_paths.py` |
| 另一台设备打不开 | 防火墙/IP 不对 | 本机先试 127.0.0.1，再查防火墙 |
| 转写很慢 | 没显卡/驱动 | 用转写机同步 kb.db，或换带显卡机器 |
