# 交付安装说明：怎么给老板用

> 两种方式，先选一种：
> **A. 局域网访问**（推荐）：服务跑在你这台机器上，老板用浏览器打开，**他那台电脑什么都不用装**。
> **B. 装到老板电脑**：把整个目录拷过去，跑一个安装脚本，以后他那台机器独立运行。

---

## 方式 A：局域网访问（5 分钟，推荐）

适合：老板和你在一间办公室/同一个网络；你的机器能常开。

### 你要做的

1. 查本机 IP：

   ```powershell
   ipconfig | findstr /i "IPv4"
   ```

   例如 `192.168.1.23`。

2. 放行端口（管理员 PowerShell 执行一次）：

   ```powershell
   netsh advfirewall firewall add rule name="KB 8010" dir=in action=allow protocol=TCP localport=8010
   ```

3. 启动：

   ```
   双击 start_all.bat
   ```

4. 用手机或另一台电脑测试：`http://192.168.1.23:8010`，能打开登录页就通了。

### 老板要做的

打开浏览器，输入你给的地址 → 输入账号密码 → 用。

**他的电脑不需要装任何东西。**

### 必须注意

- 你的电脑不能关机、不能休眠（电源选项设“从不睡眠”）；
- 你换网络（比如从公司到家里）IP 会变，要重新告诉他；
- 老板电脑和你不在同一网络时，A 方案不可用，走 B。

---

## 方式 B：装到老板电脑（约 30 分钟）

适合：老板要独立用、要带走、或你们不在同一网络。

### 前提条件

| 项 | 要求 | 不满足会怎样 |
|---|---|---|
| 系统 | Windows 10/11 64 位 | 装不上 |
| Python | 3.10（64 位） | 装不上依赖 |
| 显卡 | NVIDIA 显卡（建议 6GB 显存以上） | 转写回退 CPU，速度慢 10 倍以上 |
| 磁盘 | 至少 10 GB 空闲 | 模型放不下 |
| 网络 | 能访问 `api.deepseek.com` | 问答不可用（转写仍可离线） |

> 没有 NVIDIA 显卡也能跑，但转写会很慢。折中办法：用 `--model small`，或把转写放在你这台机器上做，只把 `kb.db` 和 `data/raw` 拷给他。

### 要拷贝的东西

整个 `D:\知识库问答系统` 目录（约 **3.5–4 GB**）：

```
知识库问答系统\
├─ *.py / *.html / *.bat        代码与脚本
├─ .venv\                       ❌ 不要拷（路径绑定，安装脚本会重建）
├─ models\                      ✅ 转写模型 1.5GB + 向量模型 24MB
├─ cuda\                        ✅ cuDNN + cuBLAS（约 1.8GB）
├─ wheels\                      ✅ 离线依赖包 114MB
├─ data\                        ✅ kb.db、raw、library、backup
├─ config.local.json            ✅ API Key、登录密码（注意保密）
└─ requirements.txt             ✅
```

### 老板电脑上的操作（5 步）

1. 把整个目录拷到 `D:\知识库问答系统`（换个盘也行，但**路径里不要有中文以外的特殊符号**）；
2. 安装 Python 3.10（勾选 Add to PATH）；
3. 右键 `install_new_pc.ps1` →「使用 PowerShell 运行」；若提示策略限制，打开 PowerShell 执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File "D:\知识库问答系统\install_new_pc.ps1"
   ```

   脚本会：建虚拟环境 → 离线装依赖 → 检查模型 → 修复数据库路径。

4. 双击 `start_all.bat`，浏览器自动打开；
5. 跑一次自检：

   ```powershell
   .venv\Scripts\python.exe healthcheck.py
   ```

   全部 PASS 即可。

### 可选的收尾

- 开机自启：`powershell -ExecutionPolicy Bypass -File install_autostart.ps1`
- 改密码：`.venv\Scripts\python.exe set_password.py 新密码`
- 备份：`python backup.py`（监听进程每天 3 点自动跑）

## 给老板的东西（三样就够）

| # | 给什么 | 形式 |
|---|---|---|
| 1 | 访问地址 + 账号密码 | 微信发一条 |
| 2 | 《使用说明》 | `老板使用说明.docx`，打印或发文件 |
| 3 | 一句话 | “答案后面有时间/页码，点一下能跳回原文；觉得不对点 👎” |

---

## 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 老板打不开 | 服务没启动 / 防火墙 / 不同网段 | 先在本机开 `127.0.0.1:8010` 试；再查 IP 和防火墙 |
| 登录不上 | 密码不对 / 改过没告诉他 | `set_password.py 新密码` |
| 转写特别慢 | 没识别到显卡 | `healthcheck` 看设备；无显卡用 `--model small` |
| 换了文件夹后打不开视频 | 数据库里是旧路径 | 运行 `fix_paths.py` |
| 导入的 PDF 提示“需要 OCR” | 扫描版没有文字层 | 换文字版 PDF，或后续接 OCR |
